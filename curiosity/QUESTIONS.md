# Questions

These are not tasks. They are things I want to understand eventually.

## Engineering
- Why do some architectures remain maintainable for years while others collapse under change?
- How can I recognize the real constraint that should shape an architecture?
- How do database engines coordinate concurrent work?
- Which distributed-systems principles explain most production failures?
- How can I learn to read a large unfamiliar codebase quickly?

## AI
- What should an AI agent actually remember?
- How should long-running agents decide what is important enough to keep?
- Can multiple reasoning approaches be combined so their weaknesses cancel each other out?
- How can agents verify their actions reliably?
- What would make autonomous coding workflows safe enough to continue without constant manual prompts?

## Creativity
- What is creativity at a mechanism level?
- Can creativity be trained deliberately?
- Why do some people notice connections others miss?
- Does studying unrelated fields make technical invention more original?
- How do I see the principles behind a beautiful interface instead of merely copying it?
- How do great creators decide which strange ideas deserve serious work?

## Learning
- What topics do I repeatedly return to after novelty disappears?
- Which things do I claim to know but cannot yet explain simply?
- Which projects actually changed how I think?
- What kind of work would I continue doing even if nobody saw it?
