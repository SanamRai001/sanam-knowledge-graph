# Month 1 Learning Plan

**Cycle:** 2026-09-25 → 2026-10-24  
**Theme:** Strengthen the foundations beneath backend, system design, and AI work.

## Rule for this month

This plan is intentionally small.

If I discover an interesting topic while studying:

1. write it in `learning/LEARNING_BACKLOG.md` or `curiosity/QUESTIONS.md`;
2. do not switch focus;
3. only investigate it immediately if it blocks the current topic.

## 2. How a Web Request Actually Travels

**Dates:** 2026-10-06 → 2026-10-14  
**Priority:** Required

### Minimum understanding
Be able to explain this path in my own words:

```text
URL
 ↓
DNS
 ↓
IP address
 ↓
TCP connection
 ↓
TLS (for HTTPS)
 ↓
HTTP request
 ↓
reverse proxy / server
 ↓
application
 ↓
database or other service
 ↓
HTTP response
```

Understand at a practical level:

- what DNS does;
- what TCP gives the application;
- what HTTPS/TLS adds;
- request vs response;
- common HTTP methods and status-code groups;
- where a reverse proxy such as Nginx fits.

### Evidence
Draw the request lifecycle for one of my own deployed applications and explain every step.

### Do not expand into
- advanced routing protocols;
- packet-level networking;
- BGP;
- load-balancer algorithms;
- deep cryptography.

Capture those for later.
