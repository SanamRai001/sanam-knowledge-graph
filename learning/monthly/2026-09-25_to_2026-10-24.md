## 1. PostgreSQL Foundations + Transactions

**Dates:** 2026-09-25 → 2026-10-07  
**Priority:** Required

PostgreSQL is part of this month's database foundation. It is **not** an additional fourth topic.

### Minimum PostgreSQL understanding

By the end, I should be able to do and explain:

- what PostgreSQL is and where it fits in a backend system;
- install/use PostgreSQL locally and connect with `psql`;
- create and drop a database;
- create tables;
- common data types;
- primary keys and foreign keys;
- `NOT NULL`, `UNIQUE`, `CHECK`, and sensible constraints;
- `INSERT`, `SELECT`, `UPDATE`, and `DELETE`;
- `WHERE`, `ORDER BY`, `LIMIT`;
- basic aggregate functions and `GROUP BY`;
- inner and left joins;
- basic schema relationships;
- what an index is for at a practical level.

### Transactions & concurrency

I should also be able to explain:

- what a database transaction is;
- ACID at a practical level;
- `BEGIN`, `COMMIT`, and `ROLLBACK`;
- why concurrent requests can create bugs;
- dirty reads;
- non-repeatable reads;
- phantom reads;
- the purpose of isolation levels;
- PostgreSQL's practical transaction/isolation behavior at a beginner level.

## 2. How a Web Request Actually Travels

**Dates:** 2026-10-08 → 2026-10-15  
**Priority:** Required

### Minimum understanding

Be able to explain this path in my own words:

```text
URL
 ↓
DNS
 ↓
IP address
 ↓
TCP connection
 ↓
TLS (for HTTPS)
 ↓
HTTP request
 ↓
reverse proxy / server
 ↓
application
 ↓
PostgreSQL or another service
 ↓
HTTP response
```

Understand at a practical level:

- what DNS does;
- what TCP gives the application;
- what HTTPS/TLS adds;
- request vs response;
- common HTTP methods and status-code groups;
- where a reverse proxy such as Nginx fits;
- where the PostgreSQL connection/query happens in the request lifecycle.

### Evidence

Draw the request lifecycle for one of my own applications and explain every step.

### Do not expand into

- advanced routing protocols;
- packet-level networking;
- BGP;
- load-balancer algorithms;
- deep cryptography.

Capture those for later.
