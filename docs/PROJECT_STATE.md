## Branch model
- `main` — generic reusable skeleton only.
- `sanam` — personal knowledge, learning map, ideas, questions, projects, and reflections.

## Completed phase

## Decisions

- Future personal updates target `sanam`.

- Use evidence-based knowledge levels rather than binary "know / don't know".
- Keep personal branch content non-sensitive because the repository is public.

## Verification

- `sanam` exists from the current `main` template.

## Risks
