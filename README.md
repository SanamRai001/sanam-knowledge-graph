# Sanam Knowledge Graph

A reusable, Git-based framework for mapping what you know, what you're learning, what you're curious about, and what you want to build.

> **Learn → Understand → Connect → Build → Reflect → Evolve**

## Why this repository exists

Most learning systems collect notes. This repository is designed to track **understanding**.

It gives you a place to record:

- what you already know
- how deeply you know it
- evidence from projects and experiments
- what you are currently learning
- unanswered questions
- interesting connections between ideas
- things you want to explore later
- principles you have developed
- how your thinking changes over time

## Start your own knowledge graph

1. Fork this repository.
2. Create a personal branch, for example `your-name` or `personal`.
3. Keep `main` as the reusable template if you want to pull future template improvements.
4. Fill your personal branch with your own knowledge.
5. Commit changes as your understanding evolves.

## Suggested knowledge levels

| Level | Meaning |
|---|---|
| 0 | Heard of it |
| 1 | Can explain the basic idea |
| 2 | Can use it with guidance |
| 3 | Can use/build with it independently |
| 4 | Understand trade-offs, limitations, and failure modes |
| 5 | Can design, teach, or review systems using it |

Levels are not trophies. They are an honest snapshot of current understanding.

## Philosophy

- Be honest about what you know.
- Prefer evidence over confidence.
- Track gaps instead of hiding them.
- Learning something is not the same as mastering it.
- Build small experiments to test understanding.
- Record connections between different fields.
- Let your knowledge map change as you change your mind.
- Do not turn every interesting idea into a full project.

## Your personal data belongs on your branch

The `main` branch of this repository intentionally contains only the reusable skeleton.

Personal knowledge, reflections, goals, and history should live in a separate branch or in your fork.

That keeps the project easy for other people to reuse.
